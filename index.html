College Campus

Verified Campus Network · React 19 · Node/Express · WebSockets · Docker/K8s

College Campus works like LinkedIn for Indian campuses. Students and faculty build a professional profile, verify it with their college documents and connect across institutions — in a navy-and-gold app that runs on the web, Android and iOS from one React codebase.

How I built it

  • Typo-tolerant search across people, colleges, posts and hashtags using trigram similarity.
  • One authenticated WebSocket channel for direct messages (typing indicators, read receipts), notifications and live chat.
  • Go live from the phone camera over peer-to-peer WebRTC — viewers join, chat and send hearts in real time.
  • Document-based verification — admins review ID proofs through private, expiring links in an admin console with moderation, verification and support queues.
  • Security: bcrypt passwords, revocable JWT sessions, Google sign-in, rate limits & lockouts, Helmet CSP/HSTS, a CORS allow-list and byte-level upload checks.
  • In-memory TTL cache for hot reads, Winston logging and Sentry error monitoring.
  • Docker Compose (API + Nginx), Kubernetes manifests (Deployment, Service, Ingress, PVC), Netlify + Render deploys and AWS S3 for media; Capacitor for Android & iOS.

WEARSUPER

MERN E-commerce · React 19 · Express 5 · MongoDB · JWT

A premium streetwear storefront built around an Apple-style, scroll-driven hero — backed by an Express + MongoDB API with real accounts, a product catalogue and orders.

How I built it

  • Cinematic hero — a 240-frame image sequence scrubbed by GSAP ScrollTrigger, loaded progressively (a lighter 120-frame set on phones).

  • Orders in MongoDB — the server re-prices every line from the database, validates size & colour and issues order, tracking and invoice numbers.

  • Luxury product pages with hover-zoom, a drag-to-rotate 360° viewer, reviews, wishlist and a multi-step (simulated) checkout.
  • API hardened with Helmet, a CORS allow-list and input validation; 17 API tests on an in-memory MongoDB (Node test runner + Supertest).

Rescuen

Personal Safety App · React Native · Kotlin · Firebase · Google Gemini · Live on Google Play

A community-powered emergency-response app for Android. One trigger alerts nearby Rescuen users within 1 km, family contacts and the police — while recording evidence, even with the screen locked.

My Role

Built and launched as a two-person team: I built the Android app (React Native with a Kotlin native layer), while my teammate owned the backend and cloud.

How it works

  • One-tap (hold) SOS — SMS to family and emergency services (112), plus instant FCM alerts to nearby users.
  • 1 km community radar using geohash proximity queries to reach Rescuen users close by.
  • Live location with background tracking through an Android foreground service, so SOS keeps running with the screen off.
  • Follow-Me safe-journey mode — if you stop unexpectedly it asks “Are you safe?” and triggers SOS if you don't respond.
  • Private, PIN-locked Evidence Vault that records video + audio from the front and rear cameras to owner-only cloud storage.
  • AI safety assistant on Google Gemini with function-calling to guide users and trigger SOS.
  • Custom Kotlin native module for triple volume-key SOS and lock-screen wake; Google Sign-In + phone OTP onboarding; UI in six Indian languages.
  • Published & live on the Google Play Store.

Face Mask Detection

Computer Vision · Python · TensorFlow/Keras · OpenCV

A deep-learning pipeline that trains a mask classifier and runs it live on a webcam feed.

How I built it

  • Transfer learning on MobileNetV2 (ImageNet weights) with a custom dense head and a sigmoid output.
  • Data augmentation — rotation, zoom, shifts, shear and flips — with a 20% validation split.
  • Accuracy and loss curves plotted with Matplotlib; the trained model is saved as .h5.
  • Live inference — OpenCV Haar-cascade face detection → 224×224 crop → prediction, drawn as a labelled box.
